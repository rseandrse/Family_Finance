# Тренажёр «Швартовка лагом»

Вся игра — один файл `index.html`. Сервер и установка не нужны: файл работает прямо в браузере телефона, без связи с другими телефонами. Интернет нужен только для шрифтов; без сети игра тоже работает, но обычным системным шрифтом.

## Как открыть на iPhone

На iPhone приложение «Файлы» показывает HTML только как статичный просмотр, и игра в нём не запустится. Есть два способа.

**Способ 1. Редактор кода с предпросмотром (можно и играть, и дорабатывать).**
1. Установите редактор, который умеет показывать HTML-страницы, например Textastic (платный) или любой другой с функцией Preview.
2. Распакуйте архив в «Файлах» (тап по zip) и откройте `index.html` в этом редакторе.
3. Нажмите кнопку предпросмотра — игра запустится. Если поменять код и снова открыть предпросмотр, изменения будут видны сразу.

**Способ 2. Выложить на бесплатный хостинг и открыть ссылкой в Safari.**
Подойдёт любой хостинг статических страниц (например, Netlify Drop или GitHub Pages): загрузите туда `index.html` и откройте полученную ссылку. В Safari через «Поделиться → На экран „Домой“» игру можно добавить иконкой на главный экран. Ссылку можно отправить кому угодно.

На компьютере всё проще: двойной щелчок по `index.html` открывает игру в браузере.

## Как обмениваться доработками

Пришлите друг другу изменённый `index.html` через Telegram, WhatsApp или AirDrop. Файл небольшой, а всё нужное для игры находится внутри него.

## Где что в коде

Все настройки находятся внутри `<script>`.

- `const C={...}` — физика лодки:
  - `mx`, `my`, `Iz` — масса и инерция;
  - `Tmax`, `Tidle` — упор винта на полном газу и на холостом;
  - `Cr` — эффективность руля;
  - `wash` — поток от винта на руль;
  - `pw` — сила заброса кормы;
  - `Kax`, `Kay` — парусность;
  - `reach` — с какого расстояния матрос может подать конец (м);
  - `breakT` — нагрузка, при которой рвётся швартов (Н).
- `const LINES=[...]` — швартовы и направление на тумбу.
- `makeSteps()` — пункты чек-листа и их тексты.
- `evalSteps()` — проверки чек-листа: скорость в зоне, зазор, угол и т. д.
- `finish()` — подсчёт баллов.
- `SC={...}` — сценарий по умолчанию:
  - `side` — борт;
  - `wind`, `wKn` — направление и сила ветра;
  - `cur`, `cKn` — течение;
  - `gap` — длина свободного места;
  - `pw` — двигатель: `1` — Yanmar, корму заносит влево; `-1` — Volvo, корму заносит вправо; `0` — без заброса.

## Звук и вибрация

Кнопки с динамиком и телефоном справа на карте. Звук двигателя синтезируется в коде (функции `sndInit` и `fxUpdate`), файлов со звуками нет. На iPhone звук не слышен в беззвучном режиме. Вибрация с ростом оборотов работает на Android; Safari на iPhone не даёт сайтам управлять вибромотором, там возможны только лёгкие отклики на iOS 18 и новее.

Управление на компьютере: стрелки ↑/↓ — газ, ←/→ — руль, пробел — нейтраль, `c` — руль прямо.
